<header class="major">
    <h3>Topics</h3>
</header>

<p>From a technical point of view, we will study gaming history, basic maths, anatomy of game engines along with real engines (Unreal Engine, Unity, Godot), game design and narrative, gameplay and user interfaces, gaming engagement, backends, privacy, programming, GPU programming (very briefly), animations, physics, networking, and AI.</p>

<p>No textbook is required, but if you want to buy one, "Game Engine Architecture" by Jason Gregory is a very comprehensive book that covers every aspect for an initiation to game development.</p>
